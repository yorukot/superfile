### How to write hotkeys

Each hotkey is a list of keys. Write printable characters as they are (`a`, `A`, `?`), and other keys by name (`enter`, `esc`, `tab`, `space`, `pgup`, `f1`). Modifiers go in the order `ctrl`, `alt`, `shift`, for example `ctrl+shift+left`.

```toml
copy_items = ['ctrl+c', 'y']
```

The first key can't be empty. `''` is only a placeholder.

:::caution

Please do not use hotkeys with ascii codes conflicting with keys used to control superfile:

- `Ctrl+M` - conflicts with `Enter` Key
- `Ctrl+I` - conflicts with `Tab` Key
- `Ctrl+?`, `Ctrl+[` - conflicts with `Delete` and `Backspace` Key

:::

:::note

superfile doesn't check for conflicts. If a key is bound to two actions, only one of them runs, so avoid reusing keys.

:::

Missing hotkeys use their default keys. Run `spf --fix-hotkeys` to add them to your file (comments are lost; a backup is kept).

### Default superfile hotkeys

:::caution

If you are a vim user, the default hotkeys may make you hate superfile.

:::

superfile default hotkeys design concept:

- All hotkeys that will change to files use `ctrl+key` (As long as you don't press ctrl your files will always be safe). The exceptions are `delete` and `D` (shift+d), which ask you to confirm before deleting.
- Non-control file classes use the first letters of words as hotkeys.
