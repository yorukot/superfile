---
title: AI policy
---

Feel free to use AI for the website, documentation, and other work outside the core file manager. The usual [PR checklist](https://github.com/yorukot/superfile/blob/main/CONTRIBUTING.md#pull-request-checklist) applies.

If you use AI to change the core file manager, read the relevant Go code first. Before requesting review, read every line the AI changed and test the behavior yourself. Be ready to explain how the change works.
